# VaultOS

> Give software the ability to move money — without giving AI the keys.

Autonomous treasury and invoice payments on Arc. AI agents analyze invoices and *request* payments;
a smart-contract treasury decides whether they are allowed. Full spec: [`vaultos_arc_hackathon_prd.md`](./vaultos_arc_hackathon_prd.md).
